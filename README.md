# Sistema de Controle de Gastos

Trabalho final da disciplina de Programação Orientada a Objetos (POO). Projeto acadêmico em **Java**, integrado a um banco de dados **PostgreSQL**.

## Sobre o projeto

O sistema controla gastos e aplica os conceitos de Programação Orientada a Objetos, conectando a aplicação Java a um banco de dados SQL. O código é comentado e explica o que cada parte faz.

## Tecnologias

- Java
- PostgreSQL

## Como executar

1. Instale o **JDK** e o **PostgreSQL**.
2. Baixe ou clone este repositório.
3. Abra o projeto no Eclipse (`File > Import > Existing Projects into Workspace`).
4. No PostgreSQL, crie um banco de dados vazio.
5. No código, altere a conexão (URL, usuário e senha) para os dados do seu banco.
6. Crie as tabelas no banco. O projeto **não inclui um script `.sql`**: as tabelas devem ser criadas conforme o que o código da aplicação utiliza. As classes e os comentários explicam a estrutura esperada.
7. Execute a classe principal do projeto.

## Observações

Por ser um trabalho acadêmico, o código contém `System.out.println` para acompanhar o funcionamento no console. Em um sistema real isso não seria feito dessa forma.
